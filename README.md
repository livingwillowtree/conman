# ConMan6767

Simple simulation of Conway's Game of Life in pygame.

---

## Key Features

* **Simple Optimization:** Keeps track of only living cells for main grid data. Evaluates only live cells and its adjacent cells
* **Edit Mode:** Add or remove cells when not running simulation.
* **Start/Stop Simulation:** Easily start and stop simulation.
* **Free Roam Spectate:** Zoom and camera pan.

---

## Controls

* **Left Click:** Edit Cell
* **Right Click + Drag:** Pan Camera
* **Scroll Up / Down:** Zoom in / out
* **`A` / `D`:** Switch write mode (Add / Delete)
* **`C`:** Clear the entire grid
* **SPACE:** Start / Stop simulation
* **`S` / `F`:** Change simulation speed (Slower / Faster)
* **`ESC`:** Exit game
